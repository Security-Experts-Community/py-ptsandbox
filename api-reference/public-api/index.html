Public API client

Access this client through sandbox.api. It uses the API token from SandboxKey. Methods inherited from the storage, analysis, scanning, and maintenance mixins are listed below.

ptsandbox.sandbox.api.SandboxApi

Bases: StorageMixin, AnalysisMixin, ScanMixin, MaintenanceMixin

download_artifact async 

download_artifact(file_uri: str, read_timeout: int = 120) -> bytes

Download file from the sandbox by hash

Parameters:

  • file_uri (str) –

    Permanent file identifier in the sha256:<sha256_hex> format.

    This is not the same as the temporary file_uri returned by :meth:upload_file (sfm:stream_v1...), which is only valid for use with scan creation endpoints.

  • read_timeout (int, default: 120 ) –

    response waiting time in seconds

Returns:

  • bytes –

    File data

Raises:

  • ClientResponseError –

    if the server returns an error status (404 if the file is not found)

  • ClientError –

    on connection or transport errors
